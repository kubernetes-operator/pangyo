# 03. UI 설계

## 2패널(2개의 물리 디스플레이도 추후 지원)
```text
┌──────────── Display A : ORGANIZER ────────────┐  ┌──────── Display B : WRITER ────────────────┐
│ MEMONEST  [KO/EN] [Sync: Off]                 │  │ 2026-10-29  저장됨  오늘 00:04:11          │
│ [Battery: --] [WiFi: --] [Bluetooth: --]      │  │ 제목: Sample                                  │
│ [New Note] [New Folder] [Search]              │  │ ───────────────────────────────────────────   │
│ Root                                           │  │                                              │
│ ├─ Work                                       │  │ Markdown 또는 Plain Text만 편집               │
│ │  └─ Project                                 │  │                                              │
│ │     └─ draft.md                             │  │                                              │
│ └─ Personal                                   │  │                                              │
│    └─ idea.md                                 │  │ [Tab] 들여쓰기 / [Shift+Tab] 내어쓰기       │
│ [Tree / Radial]                               │  │ [Ctrl+Z/Y] [Download] [Sessions]            │
└────────────────────────────────────────────────┘  └──────────────────────────────────────────────┘
```

## 1개 화면
- `관리 화면` ↔ `집중 편집 화면`을 F6 또는 버튼으로 전환. 회전하는 느낌의 CSS 애니메이션(접근성 감소 동작 설정 존중).
- 시각적인 3D 전환은 장식이고 두 상태의 기능을 동일하게 유지.
- 편집 화면에서 디렉터리 탐색/과도한 제어는 감춤.

## 상태 정보 처리
- 날짜/시간: OS 시스템 시계.
- 배터리/Wi-Fi/블루투스: 웹 브라우저에서는 표준 API 제한으로 **신뢰할 수 있는 세부 상태를 일관되게 얻을 수 없음**. 현재 `--` 또는 Online/Offline만 표시.
- Native는 OS별 권한이 승인된 경우에만 플랫폼 어댑터로 읽음. FreeBSD는 하드웨어별 `ifconfig` 등과 드라이버 진단 기반.
- 언어: UI 로캘 ko/en, 텍스트는 UTF-8. 추가 입력 언어는 OS 입력기 또는 FreeBSD 별도 IME 지원 확인 대상.

## 키보드 UX(초기 프로토타입)
- F6: 단일 화면 전환.
- Tab / Shift+Tab: 선택 줄 그룹 들여쓰기 / 내어쓰기.
- Ctrl/Cmd+Z, Ctrl/Cmd+Y, Ctrl/Cmd+Shift+Z: 250개 저장 스냅샷 기반 Undo/Redo.
- 기본 브라우저의 복사/붙여넣기/선택을 사용.
- Web의 폴더 트리/2패널은 초기 시연, native 물리 2화면 분리는 후속 개발.
