# 10. FreeBSD ARM64 전용 장비 설계

## 전용 장비의 성격
- FreeBSD arm64(=aarch64) 기반 저전력 SBC/커스텀 메인보드 후보 선정.
- 앱 실행 외의 일반 데스크톱·브라우저·런처를 UI에 노출하지 않음.
- 단일 디스플레이: Rust TUI부터 구현. F6으로 파일 트리 ↔ 글 편집 전환.
- 2개 디스플레이: GUI/DRM/프레임버퍼 지원 조사 후 별도 compositor 구현. **TUI만으로 자동 지원된다고 볼 수 없음.**

## 하드웨어 승인 체크리스트
- FreeBSD 부팅/스토리지 장치 인식 및 안정성.
- 디스플레이 컨트롤러, 1/2화면 출력과 전력 사용량.
- UTF-8 한글 렌더링과 조합형 IME 실제 키보드 테스트.
- Wi-Fi 모듈의 FreeBSD 드라이버/펌웨어 및 IEEE 802.11 연결 테스트.
- Bluetooth 칩셋/HID/페어링 사용 가능성.
- 배터리/충전 상태 센서와 OS 접근 인터페이스.
- 입력 지연과 저장 매체 수명, 전원 강제 제거 시 파일 일관성.

## 최소 OS 정책
- `/bin/sh` 기본, Bash가 필요한 경우 `pkg install bash` **후** 선택 (FreeBSD 기본 제공이라고 가정하지 않음).
- 전용 사용자 계정, 로그인 시 앱 자동 실행, 쓰기 가능한 저장 경로 제한.
- 앱에서 임의 셸 명령 실행 금지. 시스템 관리 콘솔은 별도 보호 절차 필요.
- 장비별 서비스 자동 실행과 복구는 boot 환경 검증 후 rc.d 스크립트 배포.

## 현재 코드 (로드맵 08, 2026-11-09)
- `apps/bsd`: **전체 화면 TUI** (ratatui). 단일 화면 F6 전환/넓은 터미널 두 칸, 폴더 2단계, md/txt, 한글 폭, Undo 250, 5초 자동 저장, 상단 기기 상태. 사용법·검증 범위: `apps/bsd/README.md`.
- 키오스크: `apps/bsd/kiosk/` — 전용 계정 + ttyv0 자동 로그인 + 재실행 실행기, 멱등 설치 스크립트.
- 검증: `scripts/bsd-vm-verify.py` — FreeBSD 15.0-RELEASE arm64 공식 VM 이미지(SHA256 검증)를 QEMU로 실행해 빌드·테스트·TUI 실행·키오스크 설치 확인. **실기기·한글 입력기·2화면은 미검증.**

## 이전 기록
- `apps/bsd`는 줄 단위 **콘솔 편집기**. 경로 규칙과 파일 저장은 `crates/core`를 공유(웹과 같은 규칙).
  - 명령: `:new`/`:open [폴더/]제목[.txt]`, `:mkdir`, `:list`(트리), `:show`, `:save`, `:quit`(미저장 경고)/`:quit!`, `:help`.
  - 메모 위치: `$MEMONEST_NOTES_DIR` 또는 `$HOME/MemoNest/Notes` (v0.1 예제와 동일 → 기존 파일 그대로 열림).
  - Linux x86_64에서만 빌드/테스트됨. **FreeBSD aarch64 빌드·실기기 검증 전**, 프로덕션 키오스크가 아님. 전체 화면 TUI(F6 전환)는 후속.
