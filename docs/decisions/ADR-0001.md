# ADR-0001: 로컬 우선 아키텍처
- 상태: **제안**, 2026-10-29.
- 맥락: 29개 요구는 오프라인 장비/개인 파일 소유권/서버 선택 연결을 포함.
- 결정 후보: 웹 UI 공통, Tauri 2 네이티브, FreeBSD Rust TUI, Go API + Postgres/S3.
  - 2026-11-04: 서버 언어는 ADR-0002로 대체(Go → Rust/axum). 로컬 우선 원칙은 유지.
- 장점: 경량 웹 UI, 서버 부재 시 메모 기능 유지.
- 비용: 네이티브 파일 어댑터와 BSD 클라이언트는 별도 개발; 2화면/IME/동기화 보장 어렵다.
- 미결정: 요구 28 단일 편집 잠금은 사용자 승인 전 코드에 반영하지 않음.
