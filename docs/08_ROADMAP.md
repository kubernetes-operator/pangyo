## 1차 Release Gate
- 오프라인에서 앱 재시작 후 노트 보존.
- 0/1/2단계 폴더, 긴 본문, MD/TXT 다운로드 테스트.
- 250회 Undo/Redo 및 세션 누적 확인.
- Git, Kubernetes, 클라우드 키 없이도 로컬 메모 작성 가능.
- 서버 미구현 기능은 사용자에게 ‘미지원’으로 분명히 표시.
