# 14. n8n 연동 안내 (로드맵 07, 요구 19)

## 1. 토큰 만들기
웹 앱 → **계정** → **자동화 토큰 (n8n)** → 이름 입력, 필요하면 *쓰기 허용* 체크, 만료(30/90/365일) → **토큰 만들기**.
`mn_pat_…` 원문은 **이때 한 번만** 보입니다. n8n → Credentials → **Header Auth**
(`Name: Authorization`, `Value: Bearer mn_pat_…`)로 저장하세요. 유출이 의심되면 같은 화면에서 **해제** → 즉시 무효.

| 범위 | 가능한 작업 |
|---|---|
| `notes:read` | 변경 목록, 메모 읽기, 검색, 연관 메모 |
| `notes:write` | + 편집 임대, 저장, 삭제 |
| (없음) | 계정·장비·토큰 관리는 토큰으로 불가 (웹 로그인 필요) |

## 2. 읽기 (HTTP Request 노드, 기본 URL `https://<도메인>/api/v1`)
- 새 변경만 가져오기: `GET /notes?since={{$json.cursor ?? 0}}` → `notes[]`, 다음 실행에 `cursor` 보관 (n8n Static Data 등)
- 검색: `GET /search?q=회의&limit=10` → `[{id, title, folder, snippet, score}]`
- 한 개: `GET /notes/{id}` / 연관: `GET /notes/{id}/similar`

## 3. 쓰기 (`notes:write`)
- **새 메모**: 클라이언트가 만든 UUID로 `PUT /notes/{새 UUID}`
  `{"baseVersion":0,"clientId":"n8n","title":"요약","folder":"자동","format":"md","content":"..."}`
- **기존 메모 수정** — 사람과 같은 규칙(ADR-0003). 다른 기기가 편집 중이면 423으로 기다립니다:
  1. `POST /notes/{id}/lease` `{"clientId":"n8n","label":"n8n"}` → `fencingToken`
  2. `GET /notes/{id}` → 현재 `version`, `content`
  3. `PUT /notes/{id}` `{"baseVersion":<version>,"clientId":"n8n","fencingToken":<token>, ...}`
  4. `DELETE /notes/{id}/lease?clientId=n8n`
  - 409 `version_conflict`: 그 사이 사람이 바꿈 → 2부터 다시. 423 `lease_held`: 사람이 편집 중 → 나중에 재시도.
- 모든 쓰기 요청 헤더에 `X-MemoNest-Request: 1` 은 **필요 없음**(쿠키가 아닌 Bearer 인증). 붙여도 무방.

## 4. 주의
- 토큰 요청 제한은 아직 계정 단위로 없습니다(로그인·가입만 IP 제한). 반복 실행 주기는 1분 이상 권장.
- 메모 본문 최대 900KB, 계정 저장 용량 초과 시 403 `quota_exceeded`.
